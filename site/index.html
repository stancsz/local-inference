DESIGN COMMITMENTS

Local by default.
Explicit at the edge.

One local gateway, a pinned model runtime, a deterministic context callback, and an optional judgment command. Each boundary has an owner.

01 / OWNERSHIP

Inference stays here

The gateway binds to loopback. It does not store cloud credentials or silently fall back to a hosted model.

02 / CONTEXT

Protect the current task

Sift counts the full request, preserves protected work, and fails closed when the required context cannot fit.

03 / RESEARCH

Keep evidence separate

Decode speed, synthetic retention, GPU accounting, and real task results stay in different evidence classes.
